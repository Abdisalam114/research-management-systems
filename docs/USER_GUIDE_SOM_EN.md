# JUST RMS — User Guide (Somali + English)

See also: **[SYSTEM_HOW_IT_WORKS.md](./SYSTEM_HOW_IT_WORKS.md)** for the full accurate flow.

---

## Somali — Sida loo isticmaalo

### Login
1. Fur system-ka (frontend).
2. Geli email + password.
3. Haddii aad tahay staff (Director, Finance, Leadership, Coordinator): dooro **UG** ama **PG**.
4. Waxaad tagtaa **Dashboard**.

### Researcher
1. Samee proposal (Voluntary ama Grant fund call).
2. Buuxi ethics haddii loo baahdo, submit.
3. Sug review stages (peer → committee → finance grant kaliya).
4. Marka la approve gareeyo, project ayaa abuurma — maamul milestones / reports / publications.

### Research Director
1. Proposal Review: **Assign & send to reviewer** (Leadership).
2. Marka peer dhammaado: **Assign & send to committee**.
3. Grant: **Assign & send to finance**.
4. Ethics: approve & issue JUREC certificate (gooni ah committee).
5. Marka Phase 3 dhammaato: **Proposal decision → Approve** (creates project).

### Leadership
- Peer Reviews: proposals aad ku assigned tahay — score 1–5 + comment.

### Faculty Coordinator
- Committee review kaliya haddii Director kuu assign gareeyay.

### Finance
- Grant proposals: `/finance/reviews` — kaliya committee passed + assigned.
- Budgets / payments / project closure finance sida menu-ga.

---

## English — Quick use

1. Log in → staff pick **UG or PG** → Dashboard.
2. Researcher submits Voluntary or Grant proposal (+ ethics if required).
3. Director assigns Leadership → peer reviews → assigns committee → (grant) assigns finance.
4. Final **Approve proposal** only after multi-stage review is complete → Project created.
5. Finance uses **Finance review** queue for grant proposals, not the general proposal review page.

Demo accounts: `director@rms.edu`, `coordinator@rms.edu`, `leadership@rms.edu`, `finance@rms.edu`, researchers e.g. `asha@rms.edu` (UG), `mahad@rms.edu` (PG).
